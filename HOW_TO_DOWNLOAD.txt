  HOW TO DOWNLOAD THE WILDFIRE-RESILIENT SUPPLY NETWORK OPTIMIZATION PROJECT
=============================================================================

QUICK ANSWER: Download as ZIP File
-----------------------------------

1. Visit: https://github.com/satasouji-svg/Code

2. Click the green "Code" button (near top-right of the page)

3. Click "Download ZIP" in the dropdown menu

4. Extract the ZIP file to your computer

5. Open a terminal in the extracted folder and run:
   pip install -r requirements.txt
   python main.py --mode demo
